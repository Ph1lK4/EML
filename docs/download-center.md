# 下载任务与缓存

左侧“下载实例”下方的“下载中心”页面统一显示整合包原文件、实例补全、运行依赖、在线模组和 GTNH 可添加模组的文件下载。任务按文件显示，附带所属实例或用途；完成文件下载并不等于实例已经安装成功，安装结果仍以原页面为准。

## 操作

- 单文件支持暂停、继续、取消；暂停时安装流程等待，继续后沿用原来的调用与安装目标。
- “全部暂停”同时阻止随后到来的文件开始传输，“全部继续”恢复队列。
- 等待中的文件可设置低、普通、高优先级；同优先级按提交顺序执行。优先级不会打断正在传输的文件。
- 最大并发可设为 1–8，默认 3。设置的是全局上限，具体安装阶段可能出于依赖顺序而使用更少连接。
- 总限速以 KiB/s 输入，0 表示不限速。所有文件传输共享同一个额度；查询 API、图标和本地缓存复制不在此文件带宽限制内。
- 并发与限速保存在启动器 `settings/downloads.json`。设置修改即生效，降低并发不会中断已开始的文件。
- “清理已结束”只清理列表，不删除缓存或实例文件。任务记录属于当前 EML 会话；失败或重启后请回原页面重新执行下载/补全，避免自动重放已失效的安装事务。

取消已导入实例的补全会保留完成的文件。关闭 EML 时先取消并等待文件流释放；可恢复的片段留在缓存，下一次相同内容请求可继续使用。

## 缓存复用

共享文件缓存位于启动器 `cache/downloads`。只有带可信 SHA-1、SHA-256 或 SHA-512 的请求才参与共享缓存，身份按最强摘要生成，不根据文件名或 URL 猜测相同内容。

每次命中均重新计算当前请求要求的全部摘要及大小，任何一项不同都不能作为有效内容发布。不同实例可以复用同一内容；文件复制到各自实例，实例内的用户修改不会反过来改变缓存。最终目标已存在时仍不覆盖。

损坏缓存会保留为诊断副本并重新下载，不会替换用户实例内的文件。并发请求相同摘要时协调缓存填充，避免重复下载。没有可信摘要的请求继续使用原有临时下载和校验策略，不加入长期共享缓存。

整合包原始归档仍保存在 `cache/instance-archives`，供 Embedded 文件恢复使用，不因清理任务列表而删除。

## 断点续传

缓存中的 `.part` 片段在取消或网络中断后可保留。续传要求相同内容摘要、相同来源地址指纹，以及服务器提供强 ETag；请求带 `Range` 和 `If-Range`，严格检查返回区间、总大小和实体标识。记录不保存完整 URL、访问令牌或认证头。

服务器忽略 Range、返回 416、文件标识变化，或切换镜像时重新下载。没有可靠恢复依据时也从头下载。片段拼接完成后重新校验完整文件的全部摘要，校验失败不会发布到实例。

限速等待不计入网络超时；无响应的网络读仍受超时控制。

## 中文整合包介绍

整合包页面直接展示 Modrinth / CurseForge 接口提供的名称与简介。平台提供中文就显示中文，只提供英文就保留英文；不调用额外翻译服务，也不再使用 EML 整理的 38 个整合包中文目录。搜索词直接传给所选平台，不根据本地别名改写。

选中项目后，右侧“项目介绍”独立读取平台完整正文。作者在正文中提供的中文和双语内容会保留；页面不会把几个汉字当作一份完整译文，也不会凭相似名称套用其他项目的说明。正文以安全纯文本显示，不执行 HTML 或自动加载远端图片。

介绍只在选中项目时读取，不为整页搜索结果逐一请求。切换项目或离开页面会取消旧请求，迟到的响应不会覆盖新项目；介绍加载失败可单独刷新，不阻止版本查询或已具备条件的下载。平台网页或浏览器自行翻译的中文若未通过 API 提供，启动器无法保证同步取得。此调整只影响整合包介绍，现有在线模组中文目录继续使用。

## 实现分工

- `EML.Core/Downloads`：文件请求、进度、任务状态和控制接口。
- `EML.Infrastructure/Downloads/DownloadTaskCenter.cs`：全局队列、优先级、暂停、取消与设置。
- `EML.Infrastructure/Downloads/DownloadBandwidthLimiter.cs`：共享限速预算。
- `EML.Infrastructure/Downloads/HttpFileDownloader.Cache.cs`：摘要缓存、续传、发布前校验。
- `EML.App/ViewModels/DownloadCenterViewModel.cs` 与 `Views/DownloadCenterView.xaml`：任务页面与线程间状态更新。

新下载业务应继续注入统一的 `IFileDownloader`，并设置 `DisplayName`、`GroupName` 与必要的初始优先级；不要另外创建不受任务中心管理的文件传输器。
