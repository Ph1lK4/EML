# 在线模组搜索与安装

从左侧导航打开 **在线模组**，在页面右上方的“安装到实例”中选择目标实例。搜索结果与模组详情分别滚动。

1. 输入关键词，选择 Modrinth、CurseForge 或全部平台。Minecraft 版本和加载器默认读取当前实例，也可以调整搜索条件。
2. 选择项目，查看图标、作者、简介、项目链接与兼容版本。选择一个精确版本和文件。
3. **自动加入必要依赖**默认开启；关闭后仍可继续，但清单会说明尚未满足的必要依赖。可选依赖默认不安装，需要逐项勾选。
4. 点击 **生成安装清单**，核对文件、来源、总大小和提示。解析过程中发现的嵌套可选依赖也会显示；更改选择后重新生成清单。
5. 点击 **确认下载并安装**。完成后在本地模组页管理启用、禁用、回收和恢复。

搜索条件不会修改实例的游戏版本或加载器。实际安装始终根据导入清单检查版本和加载器，不能通过更改搜索条件安装不匹配的文件。

## 中文显示与搜索

已收录的常见模组显示“中文名（英文原名）”，并优先显示 EML 整理的简短中文说明。可以查看平台原始简介；完整介绍和版本更新说明仍为平台原文。尚未收录的模组直接显示原文。

首批收录 54 个模组，覆盖 41 个 Modrinth 和 52 个 CurseForge 项目编号。平台覆盖分别核实：同一个模组在一个平台有中文显示，不代表另一个平台上的同名项目也会套用中文资料。

支持用已收录的中文全名或别名搜索，例如“应用能源”“旅行地图”。搜索时会提示实际使用的英文关键词，并继续保留所选版本、加载器、平台和其他筛选条件。未收录的中文关键词保持原样提交，平台可能无法找到对应结果，此时可以使用英文名。

中文资料随程序内置，展示时无需请求翻译服务。匹配依据是平台和固定项目编号；同名的其他项目不会自动套用译名。中文显示不会改动下载文件名、版本编号、依赖身份或哈希校验，也不会替换模组文件内的语言资源。

维护数据位于 `src/EML.Infrastructure/Minecraft/Mods/Online/Resources/OnlineMods.zh-CN.json`。新增条目时先通过官方接口核实项目编号，再填写中文名、英文搜索名、简短说明及中文别名。不要仅凭名称推断两个平台属于同一个项目。资料加载会拒绝重复编号；有歧义的别名不转换。

## 依赖与已有文件

- 必要依赖与用户选择的可选依赖使用相同的游戏版本、加载器条件解析，并在预览时锁定具体版本。
- 已登记且通过来源校验的依赖会列为已安装；确认安装时再次核实。来源不明的文件不会仅凭名称被认为满足依赖。
- 关闭自动必要依赖后，不会偷偷下载这些文件；用户仍需自行解决清单中的未满足依赖。
- 禁用、移除的模组不会被自动重新启用。原包文件、同名文件和相同 mod ID 不会被在线安装直接覆盖。
- 首版不进行完整的不兼容关系、加载器版本范围和模组依赖版本范围分析。平台声明相符不代表所有模组能一起运行。
- 项目依赖在最多 10 页兼容版本中优先选择稳定版，找不到时提示手动选择，避免无限请求。依赖图最多 128 个项目、32 层。

## CurseForge 备用下载

沿用当前 EML 构建的 CurseForge 授权。文件没有可用官方下载地址时，用官方 SHA-1 查询 Modrinth，只接受大小、SHA-1 均一致的唯一文件。安装后保留原 CurseForge 项目/文件编号，以及实际 Modrinth 项目/版本和摘要。

匹配不到时显示官方文件页面，需要手动提供文件。不会按名称找相似模组、拼接 CDN 地址或用另一个版本代替。平台查询或图标请求不会在日志中输出 API 密钥。

两平台保留各自固定身份。环境筛选目前只映射到 Modrinth；CurseForge 不支持的环境或分类会明确提示，不会悄悄忽略条件。全部平台的排序是在各自分页结果基础上展示，不能视作跨平台的全局排名。

## 来源、校验与中断

新增在线模组使用 `.eml-runtime/mods/state.json` 的管理记录，官方大小和摘要绑定实际内容来源。用户本地导入仍使用独立的本地 SHA-256 基线；事务恢复用的 SHA-256 不会替代官方校验。

下载首先进入启动器 `.eml-runtime/online-mods/` 暂存区，校验后交给现有模组事务提交。取消或失败会清理本次暂存文件，已经安装的文件保留并报告数量。下载完成不等于实例达到启动条件。

实例检查、缺失补全、备份往返和 GTNH 额外模组迁移沿用这些记录。主动移除不会因补全重新出现；禁用项补全时仍保持禁用。

## 代码位置

- `EML.Core/Minecraft/Mods/Online/`：平台统一模型、目录和安装接口。
- `EML.Infrastructure/Minecraft/Mods/Online/`：平台目录适配、依赖计划和下载安装。
- `EML.Core/Minecraft/Mods/IOnlineModRegistrar.cs` 与原有 `LocalModManager`：保留官方来源的事务登记入口。
- `EML.App/ViewModels/OnlineModsViewModel.cs`、`Views/OnlineModsView.xaml`：在线页面和异步状态。
- `EML.App/Services/ModIconCache.cs`：图标缓存；图标保存在启动器缓存目录，不进入实例备份。

回归测试覆盖平台分页和筛选、精确备用匹配、异步结果过期、依赖选择、计划篡改、下载校验失败、部分完成、备份和迁移。测试使用临时实例和受控平台响应，不修改用户的游戏存档。
