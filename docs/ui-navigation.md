# 界面与导航

左侧提供八个主页面：本地实例、下载实例、下载中心、在线模组、微软账号、Java 环境、启动设置、GTNH 专区。

本地实例首页保留导入、刷新和启动。右键某个实例，会先选中该实例，再显示其操作菜单。启动按钮旁的“···”提供相同入口，也可使用键盘菜单键。

| 菜单入口 | 功能 |
| --- | --- |
| 实例详情 | 路径、版本配置和导入说明 |
| 启动设置 | 跳转独立大页面，设置当前实例的玩家名、账号模式、Java、内存和 JVM 参数 |
| 模组管理 | 管理这个实例的本地模组 |
| 文件检查 | 快速检查、完整检查及检查结果 |
| 补全实例依赖 | 下载与修复进度、逐文件结果 |
| 运行日志 | 启动状态、游戏输出和停止入口 |
| 重命名、导出、删除 | 沿用现有实例管理规则及确认流程 |

实例功能在独立面板中展开。打开时焦点进入面板，遮罩背后的实例列表不能被键盘切换；按 Esc、关闭按钮或点击面板外的遮罩可返回。下拉框先处理自己的 Esc。关闭面板或切换主页面不会取消已确认的安装；取消仍使用对应功能的取消按钮。后台结果不会强制切走当前主页面。面板底部保留可复制的操作结果与失败原因。

在线模组使用独立主页面，右上角选择安装实例；默认游戏版本和加载器来自这个实例。搜索结果和详情各自滚动。搜索、中文信息、精确版本、必要与可选依赖以及安装预览沿用现有实现。只有打开在线页面才自动请求目录。

启动设置在 Java 环境下方以独立大页面展示。右上角选择要设置的实例；参数继续分别保存在各实例中。切换主页面保留当前输入，切换实例前需先保存修改。旧启动设置面板保留跳转入口，右键实例的启动设置直接进入大页面。

下载实例支持 Modrinth、CurseForge 整合包与 Minecraft 官方 Java 版。搜索和版本列表独立分页；选择固定版本后点击“下载并创建实例”，下载完成再确认实例名称，并自动进入原有导入和补全流程。目录查询与实例选择无关，正在运行游戏或修改实例时禁止开始安装；切换页面不会取消安装，关闭启动器会取消并等待任务退出。详见 [实例下载说明](instance-downloads.md)。

GTNH 专区包含“推荐模组”和“数据迁移”，共用右上角的 GTNH 目标选择。迁移入口由实例右键菜单移入专区，仍沿用旧实例选择、范围预览、冲突确认和恢复流程。专区只识别启动器已有实例，推荐项目的发行列表在选择项目后才请求；详见 [GTNH 专区说明](gtnh-hub.md)。

下载中心统一展示文件队列，支持暂停、继续、取消、优先级、并发数和总限速。缓存复用与断点续传在底层下载器完成，原安装流程继续管理实例的来源记录和最终状态。详见 [下载任务与缓存](download-center.md)。

## 代码组织

- `Themes/LauncherTheme.xaml`：共享颜色、卡片和控件样式。
- `Services/UiMotion.cs`：短暂的按钮悬停、按压和页面淡入。尊重 Windows 关闭动画和高对比度设置，不改变命令执行规则。
- `MainWindow.xaml`：侧栏、实例列表、右键菜单与面板外壳。
- `Views/InstanceWorkspaceView.xaml`：实例详情、检查、补全、启动、日志、本地模组和重命名；旧迁移索引保留跳转入口。
- `Views/OnlineModsView.xaml`、`AccountsView.xaml`、`JavaEnvironmentView.xaml`、`GtnhHubView.xaml`：独立功能页面。
- `ViewModels/MainViewModel.cs`：主页面与实例面板的导航状态。

此次调整不改变实例文件来源、下载校验、账号授权、启动规则和用户模组记录。导航测试验证操作目标、后台任务与页面激活；WPF 测试验证生产资源与页面模板的加载和布局。

下拉框与输入框使用统一圆角、悬停边框和焦点提示。下拉菜单保留选中标记、滚动及 WPF 选择逻辑，可编辑的 Java 路径输入不受下拉按钮遮挡。界面正文使用 14 号字，在线模组辅助信息使用 12 号字；搜索筛选按标签与控件成组换行。WPF 控件测试另覆盖选中项模板、Java 路径双向绑定、只读与禁用状态、下拉滚动高度和多行文本选择。

## 提示与额外窗口

删除实例、添加/接管/移除模组、迁移恢复、退出游戏确认，以及普通信息提示使用 `DialogPrompt`。`DialogWindow` 和 `Views/DialogSurface.xaml` 提供共享外观：EML 标识、标题与说明、操作对象卡片、可滚动正文和固定底部按钮。窗口边缘仍可调整大小，顶部可拖动；路径和详情支持复制。淡入、悬停与按压沿用 `UiMotion`，尊重系统关闭动画设置。

重要操作默认聚焦取消，关闭按钮和 Esc 都不代表确认。确认按钮使用“删除实例”“移入回收区”等具体文字。导入预览保留 Enter 提交及 128 字符名称限制；空名称在输入框旁显示错误，输入不会丢失。

GTNH 迁移的三个步骤使用同一外壳，保留来源/目标路径、额外模组的独立风险确认、文件动作表格和默认不覆盖策略。迁移预览的返回值仍区分取消、确认但保留新版冲突、确认覆盖。

Windows 的打开/保存文件选择器及回收站等系统界面仍由系统提供。所有自定义弹窗只返回用户选择，实际文件操作仍由原有 ViewModel 和服务执行。界面测试在隔离 STA 中离屏渲染真实内容，检查小窗口、长路径、默认操作、名称错误提示以及迁移选项门槛，不触碰真实存档。
