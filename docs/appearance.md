# 外观设置

左侧“环境与设置”中的“外观设置”管理启动器界面，不改变实例、账号或启动参数。

- 主题支持暗色、亮色和跟随 Windows 应用主题。默认仍为深蓝金配色。
- 强调色与可选背景色使用六位十六进制色值。预设按钮只填充色值，点击“应用配色”后应用并保存；背景留空则使用当前主题默认值。
- 文字、选中内容、输入框、菜单、弹窗、状态信息和标题栏共享动态资源。文字自动适应实际底色；成功、警告、错误保留各自语义色，用户强调色不改变其含义。
- 壁纸只支持本机 PNG、JPG/JPEG 静态图片，不支持网址、网络共享、GIF 或视频。源文件最多 25 MiB、6400 万像素，解码后最长边不超过 3840 像素。
- 图片经过真实格式检查，重编码为独立 PNG 副本。移动原图不会破坏已设置的壁纸，选择或移除壁纸不删除原图。
- 显示方式支持填充、适应和拉伸。遮罩强度作为最低值，必要时自动增强以保证未知图片上的文字可读，页面底部会说明实际效果。输入框、菜单和弹窗保持实色。
- 主题和壁纸设置自动保存；色值需要明确应用。滑块拖动只预览，结束拖动、键盘调整或离开滑块后保存。恢复默认只重置外观。

设置位于启动器数据根目录的 `settings/appearance.json`，壁纸副本在 `settings/appearance/`。升级时保留整个 `settings` 文件夹。初始化读取失败或图片丢失、损坏会保留原文件并回退可用外观，只显示状态说明，不弹初始化错误。手动操作失败会显示原因和可复制路径，不宣称保存成功。

Windows 高对比度优先于自定义颜色，启用时暂时隐藏壁纸并使用系统色；退出后恢复个人外观。不修改 Windows 系统设置。系统文件选择器仍由 Windows 提供，其外观不由 EML 强制替换。

## 验证

`EML.App.Tests` 中的外观回归复用生产 WPF 资源，检查多种明暗配色的文字对比度、同一控件与弹窗的实时换色、文本选择、标题栏明暗、保存重读、恢复默认、坏配置、坏图片、非法路径、保存失败及 100%/200% 布局。测试使用独立临时目录，不扫描真实实例或读取账号凭据。
