EML 1.0-RC1-Logo1 · Windows x64 候选测试版

这是 RC1 的 Logo 重打包版，保留原来的程序布局和功能。
原 RC1 下载、标签及校验值不变；本包使用独立版本号和源码提交。

第一次使用

1. 完整解压这个 ZIP，把整个文件夹放在你有写入权限的位置。
   不要放到 Program Files、Windows 系统目录或只读位置。
2. 运行文件夹中的 EML.App.exe。
   不要在压缩软件里直接运行，也不要只拿走一个 EXE。
3. 在“下载实例”或“GTNH 专区”下载整合包，也可以导入已有的整合包。
4. 在“Java 环境”下载合适的 Java；启动实例时也会按需要询问是否下载。
5. 确认玩家名和启动模式，再开始游戏。

需要安装什么？

- 不需要 Visual Studio、.NET SDK 或额外安装 .NET；所需 .NET 运行时已随包附带。
- Java 和 Minecraft / 整合包不在这个启动器包里，游戏启动前仍需下载。
- 正版模式需要你自己的有效 Minecraft 账号。离线名字不能代替正版认证。
- 不要求管理员权限。首次下载需要网络和足够的磁盘空间。

已有旧版 EML？

请先阅读同目录 UPGRADE.txt。退出游戏与 EML，备份整个旧文件夹，
保持旧安装路径，仅覆盖新版程序文件。不要删除旧实例和隐藏数据目录。

RC1 尚未完成没有 Visual Studio、.NET 和 Java 的干净电脑验收。
