EML 1.0-RC2 · Windows x64 候选测试版

第一次使用

1. 完整解压这个 ZIP，把整个文件夹放在你有写入权限的位置。
   不要放到 Program Files、Windows 系统目录或只读位置。
2. 运行根目录的 EML.exe。
   app 文件夹是程序的一部分，不能删除；不要只复制 EXE，
   也不要在压缩软件内直接运行。
3. 在“下载实例”或“GTNH 专区”下载整合包，也可以导入已有包，
   或从其他启动器复制受支持的实例。
4. 在“Java 环境”准备合适的 Java；启动时也会按需要询问下载。
5. 核对实例、玩家身份和启动模式，再开始游戏。

为什么根目录变整齐了？

RC2 将主程序 DLL、.NET 运行库、cs/ko 等语言资源和公开登录配置
放进 app 文件夹。它不是单文件 EXE；请保留完整的 app 文件夹。
EML 接续 Logo 用于程序图标、窗口及界面侧栏。

实例、设置、已下载的 Java、缓存仍保存在 EML.exe 旁边的
instances、settings、runtimes、cache 等目录，不放进 app。
这些玩家数据不随下载包附带，会在你实际使用后产生。

需要额外安装什么？

- 不需要 Visual Studio、.NET SDK 或另装 .NET，所需运行时已附带。
- Java、Minecraft 和整合包不在启动器包里，游戏前仍需下载。
- 正版模式需要自己的有效 Minecraft 账号，离线名字不等于正版登录。
- 不要求管理员权限。首次下载需要网络和足够磁盘空间。

已有 RC1 或 RC1-Logo1？

先阅读同目录 UPGRADE.txt。退出游戏和 EML，完整备份旧目录，
保持原安装路径，合并新版程序文件并保留全部玩家数据。
升级后请运行 EML.exe，而不是可能仍留着的旧 EML.App.exe，
并更新旧快捷方式。升级不会自动删除旧的平铺程序文件。

来源与安全

本包仍未签名。SHA-256 用于核对内容，不能代替发布者数字签名。
Windows 或安全软件阻止运行时，请核对来源、保留错误提示并反馈，
不要关闭系统防护。对应源码见 docs/SOURCE.txt；许可证、隐私、
安全报告和详细发布说明位于 docs 文件夹。

干净电脑、真实双账号及完整整合包/服务器流程仍需要实际验收。
先使用测试实例或存档副本，不要只保留一份重要存档。
原 RC1 标签、附件和校验值不变；请使用本版本自己的校验文件。

反馈请说明版本、Windows 版本、步骤及已脱敏错误文字。
请勿发送密码、登录令牌、账号文件或未经检查的私人日志。
